## Correction — proof 4 restated and re-proven (2026-09-07)

`docs/proofs/**` is append-only, so this corrects the earlier line rather than editing it.

**The original proof 4 asserted more than it verified.** It claimed the runtime "makes 0 calls to
FMP" but checked only two things: that `env -u FMP_API_KEY python -m almanac facts` exits 0, and
that a **non-recursive** grep for the single literal `financialmodelingprep` matched nothing in
`almanac/*.py`. An exit code is not evidence of network silence, and a one-literal grep is exactly
the weak-negative-assertion flaw the A-01 adversarial review had already flagged for
`test_no_module_but_catalog_calls_the_rate_feeds`. The verdict happened to be right; the evidence
did not establish it.

```
across almanac/ and web/  -> no match outside almanac/catalog.py
```

Completing every key with all sockets blocked is a positive demonstration that the resolution path
touched the network zero times, rather than an inference from absence.
