carries no change to it.

**The scan step then failed on B-1**, at `almanac/extract.py:427` in `_call_model`. This is the
step the nightly job runs after the rates refresh, so the nightly workflow will fail at the same
point until credits are restored.

**The corpus fallback selects correctly.** The exact shell from `nightly.yml`, run locally:

```
YT_TOKEN_JSON=(absent)                 -> source=corpus
YT_TOKEN_JSON=(present, real base64)   -> source=youtube
```

and the secret's encoding round-trips: `base64 -i token.json | base64 --decode` reproduced all
746 bytes identically, and the result parses as JSON with keys
`account, client_id, client_secret, expiry, refresh_token, scopes, token, token_uri, universe_domain`.
So the fallback branch — the one that will actually execute while the YouTube quota is exhausted
— is exercised, and the youtube branch's secret handling is proven rather than assumed.

**The Vercel entrypoint imports the real app.** `api/index.py` was loaded with `cwd=/tmp`, to
