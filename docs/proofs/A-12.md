### Side effect caught and reverted: preflight writes to its own proof file

Running `scripts/preflight.py` as a diagnostic **appends a run block to `docs/proofs/A-00.md`**,
which is a protected, append-only path. Two credential-less runs left two `llm=FAIL fmp=FAIL`
blocks there — diagnostics for HAC-51, not an A-00 re-verification, and a reader would have taken
them as A-00 regressing.

Reverted on Zaeem's instruction with `git checkout -- docs/proofs/A-00.md`. Nothing genuine was
lost: the blocks were machine-generated minutes earlier, and their content is preserved above and
in HAC-51.

**The lesson, and it belongs to HAC-51:** preflight is not a read-only probe. Anyone rewriting it
must run it somewhere that does not mutate the proof record, or the act of testing the gate
corrupts the evidence the gate exists to produce. Noted on the issue.
