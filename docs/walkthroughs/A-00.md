## Three things A-00 changed about the plan

**1. The issue text's FMP endpoint is wrong.** `economics-indicators` returns HTTP 404 with an
empty body. The live path is **`economic-indicators`** — singular. Found by sweeping seven
spellings, not by assuming. Anything downstream that hardcodes the plural will fail silently
against an empty list.

**2. FMP's legacy generations are gone.** `/api/v3` and `/api/v4` now return 403 —
*"Legacy Endpoint : ... only available for legacy users who have valid subscriptions prior
August 31, 2025."* `/stable` is the only live generation. The base-discovery loop was removed;
it had no valid fallback to find and was actively harmful, since it reported only the last
base's error and so disguised a 404 as a 403.

**3. The staleness hazard is confirmed, and it constrains A-01.**

| series | newest | lag |
|---|---|---|
| `federalFunds` | 2025-12-01 | ~9 months |
| `30YearFixedRateMortgageAverage` | 2025-12-04 | ~9 months |
| `CPI` | 2025-12-01 | ~9 months |
| `treasury-rates` `year10` | 2026-09-04 | current |

A single global `max_age_days` would make Almanac declare its own rates table stale on day one
— the product would contradict its own pitch on stage. **A-01 must set `max_age_days` per
series from these observed cadences.**

## Carried into A-01

- `max_age_days` per series, derived from the table above — not a global constant.
- `CPI` is an **index level** (~326), not a percent. Checking "inflation is 3%" needs a
  year-over-year derivation from two observations 12 months apart, and the default response
  returns only 2 rows — `refresh_rates()` must widen the window with `from_date`/`to_date`.
- `facts/catalog.yaml` has ten entities scaffolded with `value: null`. Six are `source: manual`
  and need your values plus irs.gov / ssa.gov / treasurydirect.gov URLs. A test currently
  asserts the agent filled nothing; A-01 inverts it to fail on nulls.

## Carried into A-07

`videos().list(part="snippet")` first, mutate only `description`, and send the whole snippet
back. Recorded in `almanac/youtube.py`'s docstring so it can't be missed.
