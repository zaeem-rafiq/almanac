What this page is allowed to claim

And what it is not

Extraction is not reproducible. The same input yields 65–77 verdicts run to run, and the eval gate fails 2 runs in 5 — extraction sometimes drops one stale_material claim.

Cause: extract.py calls the model without a temperature, so it samples at the API default of 1.0. A fix is proposed in ADR-002 D-5 and has not been applied — it changes a shipped module and is Zaeem’s call.

So this page does not claim every number gets caught. It claims that what the judge ruled, it ruled from a rule you can read.
